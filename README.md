Beats Headphones Landing Page
A beautifully designed headphone product landing page built using HTML, CSS, and JavaScript. This project highlights responsive design, smooth scroll-based animations, and a visually appealing dark-themed interface.

 Features
Beautiful headphone landing page using HTML, CSS, and JavaScript

Dark interface for a sleek, modern look

Animations on scroll for engaging visual transitions

Mobile First development approach – built initially for mobile devices and enhanced for desktops

Fully responsive design – compatible with all screen sizes

Pleasant and clean user interface

 Mobile First
This project was developed with mobile devices as the starting point, ensuring a seamless experience on smaller screens before adapting to larger displays.

Desktop View
On desktops, additional spacing, layout enhancements, and interactions take advantage of larger real estate to enrich the user experience.

Tech Stack
HTML5 for markup

CSS3 with custom properties for layout and styling

JavaScript for interactivity and scroll-based animations

ScrollReveal.js for animation on scroll

Remix Icons for beautiful iconography
